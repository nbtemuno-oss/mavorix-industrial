## What the Poland customer needed

The machine needed to handle varied workshop jobs rather than one fixed production part: milling flat surfaces, cutting slots and keyways, drilling bolt patterns, boring holes and making replacement components when drawings or quantities changed.

A vertical turret mill fits that work because the table moves in three axes and the head can be positioned for straight or angled operations. The operator can use a vise, clamps, rotary table or a dedicated fixture according to the part being machined.

For overseas sourcing, the general name is not enough. Machines described as “4GT,” “4S,” “turret mill” or “knee mill” can differ in travel, spindle taper, motor, feed systems and included accessories. We therefore kept the working model for this project as **HJY-4GT** and tied the quotation to a written configuration list.

## Configuration selected for the Poland order

The base machine was not the full purchasing scope. The order list included several additions intended to make routine manual machining more convenient:

- Y-axis power feed.
- Pneumatic tool-change system.
- Electric Z-axis knee lift.
- Upgrade from a two-axis digital readout to a three-axis DRO.
- Export packing.

The three-axis DRO gives the operator a direct position reference for longitudinal, cross and vertical movement. The Y-axis feed supports more consistent table travel than continuous hand feeding, while the electric knee lift reduces manual effort when changing workpiece height or setup.

Pneumatic tool change also needs a clear scope. The buyer should know which spindle taper is supplied, which drawbar system is fitted, the required compressed-air pressure and which holders or collets are included. “Pneumatic tool change” should not be treated as a complete tooling package unless every item is listed.

## What a buyer should confirm before ordering a turret mill

A useful RFQ starts with the parts and operations, not only the machine model. Overseas buyers should provide:

- Workpiece material, maximum dimensions and weight.
- Required milling, drilling, boring and reaming operations.
- Critical tolerances and surface-finish requirements.
- Preferred spindle taper and existing tooling standard.
- Cutter, collet, holder, vise and fixture requirements.
- Manual or powered feed requirements for each axis.
- DRO axis count and preferred display brand, if specified.
- Site voltage, frequency and phase.
- Pneumatic supply available in the workshop.
- Guarding, manuals and conformity-document requirements.
- Installation, commissioning and operator-training expectations.
- Destination, unloading method and available floor space.

For close-tolerance work, add a sample part or acceptance test. A general statement such as “precision milling machine” does not define flatness, perpendicularity, hole position, spindle runout or repeatability.

A vertical turret milling machine is used for general milling, drilling, boring, slotting and repair work. Its movable knee and table, together with a positionable head, make it suitable for toolrooms, maintenance workshops, prototypes and short production runs.

The parameter sheet shows R8 with an NT30 reference or option. The quotation must state the selected spindle taper because the drawbar, holders, collets and pneumatic tool-change components depend on it.
