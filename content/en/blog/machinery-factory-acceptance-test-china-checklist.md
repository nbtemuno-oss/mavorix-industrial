## What is a machinery factory acceptance test?

A machinery factory acceptance test, usually shortened to FAT, is a planned check of the finished equipment at the supplier's factory before it is packed and shipped. The test compares the actual machine with the purchase order, approved specification, drawings, option list and agreed performance criteria.

For an overseas buyer, the practical purpose is simple: confirm the machine is the one ordered, see it complete an agreed test, record any open points and decide whether it is ready for packing. A short running video is useful, but it is not a complete FAT unless the operating conditions and acceptance criteria are clear.

This checklist is intended for buyers sourcing industrial machinery from China. It can be adapted for metalworking equipment, packaging machines, compressors, forming machines, auxiliary equipment and other factory systems. The exact test scope should always match the machine and the buyer's application.

## FAT and pre-shipment inspection are not the same

These two checks often happen close together, but they answer different questions.

| Check | Main question | Typical scope |
| --- | --- | --- |
| Factory acceptance test | Does the machine perform the agreed function? | Configuration, controls, dry run, loaded test, output, alarms and documents |
| Pre-shipment inspection | Is the finished order complete and ready to ship? | Quantity, appearance, accessories, labels, packing, crate markings and documents |

A standard machine with low technical risk may only need a focused running test and final inspection. A custom line, high-value machine or equipment built around the buyer's material usually needs a more detailed FAT. The decision should be made before the order is placed, while the supplier can still plan test material, operators, measuring tools and time.

## Freeze the machine specification before the test

The FAT cannot settle a requirement that was never defined. Before the test date, put the current order documents into one controlled package:

- Purchase order and final commercial quotation.
- Approved technical specification and machine model.
- Layout, working drawing or tooling drawing where relevant.
- Voltage, phase and frequency.
- Main component and option list.
- Required accessories, molds, dies, fixtures and spare parts.
- Test material and expected finished result.
- Manuals, electrical drawings and other agreed documents.

Use revision numbers or dates when drawings changed during production. A supplier may have three versions of a layout in the email history; the inspector needs to know which one controls acceptance.

For example, an [HJY-4GT vertical turret milling machine](/en/products/metalworking-equipment/hjy-4gt-vertical-turret-milling-machine/) can be ordered with different accessories and configurations. The test should verify the options actually purchased, not every option shown in a catalogue. The same applies to the arch size and line interface on an [MS-505 automatic strapping machine](/en/products/packaging-equipment/ms-505-high-speed-automatic-pp-strapping-machine/).

## Build the test around the buyer's real use

The most useful FAT starts with the production task. What material will enter the machine? What must come out? Which result would prevent the buyer from using it?

| FAT area | Practical points to confirm |
| --- | --- |
| Machine identity | Model, serial or internal order number, nameplate and overall configuration |
| Site utilities | Voltage, phase, frequency, compressed air, water or other required utilities |
| Mechanical build | Main assemblies, guards, lubrication points, fasteners, visible finish and access for maintenance |
| Purchased components | Motors, drives, PLC, sensors, pumps and other specifically agreed brands or models |
| Controls | Start, stop, mode selection, parameter setting, displays, alarms and reset behavior |
| Dry run | Motion sequence, direction, travel, unusual noise, vibration and leakage visible during the test |
| Loaded test | Agreed material, tooling, speed, cycle count, output dimensions and finished-product quality |
| Safety functions | Emergency stop, guards, interlocks and warning functions that can be tested at the factory |
| Accessories | Tooling, loose parts, consumables, spare parts and special tools included in the order |
| Documents | Manual, wiring diagram, parts list, test record and certificate copies included in the agreed scope |

Avoid acceptance wording such as “runs well” or “quality is good.” It is much easier to review “ten consecutive cycles with the agreed tube size” or “finished length checked at three positions against the drawing.” Not every criterion needs to be complicated, but it should be observable.

## Ask for a loaded test when the material matters

A dry run confirms basic movement and controls. It does not prove how the machine behaves with the buyer's product. Where practical, arrange a loaded test using the real material, workpiece, tray, film, strap, tube, mold or a written substitute approved by the buyer.

For a [ZS-60 tube tapering machine](/en/products/metalworking-equipment/zs-60-tube-tapering-reducing-machine/), useful evidence may include the original tube dimensions, material, selected die, finished taper length and measured sample. For packaging equipment, the test may need the buyer's package dimensions and packaging material. For an air compressor system, the FAT scope is different again and may focus on configuration, controls, running condition and supplied downstream equipment rather than a full simulation of the destination factory's air demand.

Record the test conditions. A speed figure without package size, material or run duration can be misleading. If the factory cannot reproduce the final application, state what was and was not tested instead of treating the result as complete site acceptance.

## Check electrical details and destination requirements separately

Voltage, phase and frequency should be checked against the order and machine nameplate. Confirm plug or terminal arrangement, cable entry and control voltage where relevant. Photographs of cabinet components can help verify specifically agreed items, but cabinet appearance does not establish compliance with every destination-market rule.

Regulatory conformity, electrical safety, guarding and local installation requirements depend on the equipment and destination. These may require supplier documents, qualified testing, certification bodies or review by the buyer's local adviser. A sourcing coordinator or general inspector should not promise market compliance based only on workshop photos.

## Define the evidence you want to receive

An organized FAT record is more useful than dozens of unlabeled clips. Ask for evidence that lets the buyer understand what happened without standing beside the machine:

- Full machine views and nameplate photos.
- Close-ups of ordered components and options.
- A continuous view of the main test sequence where practical.
- Test material before processing and finished samples after testing.
- Measurement photos or recorded results for critical dimensions.
- A checklist showing pass, open point or not tested.
- Photos of accessories and spare parts laid out for counting.
- A separate list of deviations and corrective actions.

Photos and video should support the test record. They do not replace drawings, readings or documented acceptance criteria when those are required.

## Handle findings before packing

Finding an issue during FAT is not unusual. The important part is how it is described and closed. Separate cosmetic observations, documentation gaps and functional problems. Record the exact machine, location, evidence, agreed correction and method of recheck.

A reasonable close-out route may be:

1. Supplier confirms the finding in writing.
2. Buyer and supplier agree the correction.
3. Supplier provides new evidence or arranges a witnessed retest.
4. Buyer reviews the result and records the release decision.
5. Packing starts only when the agreed hold points are closed or accepted in writing.

The inspector reports observations; the buyer or an authorized representative decides whether the machine is accepted. Keep that distinction clear, especially when the FAT result is connected to balance payment.

## Inspect packing after the machine passes

FAT approval is not the end of shipment preparation. Before dispatch, verify loose parts, moisture and rust protection, movable-part restraint, lifting and forklift points, wooden-case construction, crate markings and packing dimensions. Photograph the machine before and after closing the case.

Heavy, top-heavy or delicate equipment needs a packing plan suited to its geometry and transport route. Destination rules for wood packaging and import documentation should be confirmed with the freight forwarder and customs adviser rather than guessed at the factory.

## When is a remote FAT enough?

A remote FAT can work for a standard machine with a clear test plan, visible results and low integration risk. It may use live video, recorded test sequences, measurement sheets and a local inspection representative. An on-site buyer or specialist is more appropriate when performance is difficult to observe remotely, several machines must operate together, software is customized or a failed test would have a large financial impact.

The choice is not simply “remote or on-site.” Buyers can also combine supplier-run tests, an independent visual inspection and remote engineering review. What matters is that each person has a defined role and the evidence answers the purchase requirements.

## FAQ

### What should be included in a machinery FAT checklist?
A machinery FAT checklist should cover identity, configuration, utilities, purchased components, controls, dry running, loaded testing where practical, output checks, safety functions, accessories, documents and open-point handling.

### Should FAT happen before balance payment?
When payment is linked to acceptance, the timing and commercial consequence should be written into the purchase agreement. The buyer should review the completed FAT evidence before making the contractual release decision.

### Is a supplier running video enough for machinery acceptance?
Not by itself. A useful video should be linked to the exact machine, test material, operating conditions and acceptance criteria. Important dimensions, configuration and documents may need separate records.

### What is the difference between FAT and site acceptance testing?
FAT happens at the supplier's facility before shipment. Site acceptance testing happens after installation and can cover final utilities, integration, production conditions and functions that could not be tested at the factory.
